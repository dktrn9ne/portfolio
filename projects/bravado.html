BRAVADO.

An agent-guided workflow and editable renderer for short product films, from source research to verified export.

Focus
Agent workflows / Creative tooling / Motion

Implementation
Python / Pillow / NumPy / FFmpeg

Status
Workflow + starter renderer

Turn source facts into a reviewable product story.

Bravado combines an installable agent skill with a Python starter renderer. The workflow studies a public project link, records what the source supports, writes a seven-scene brief, and produces a storyboard before rendering a short film with typography, diagrams, transitions, and original sound.

Source & setupWorkflow & review checklistRender runs & artifacts

Implementation choices

  • Keep facts and editable scene copy in a structured brief, with schema validation before rendering.
  • Use a frame-based timeline to coordinate motion, numeric changes, transitions, and sound accents.
  • Review storyboard and transition-boundary stills before committing to an MP4 export.
  • Verify container, video/audio contract, and full decode; watch and listen to the result for editorial quality.

Reproduce the starter demo

Clone the repository, install Python 3.10 or later and FFmpeg, then run the public Cadence starter. Initial font setup requires network access. Illustrative numbers and animation do not prove live transactions.

python -m pip install -r requirements.txt
python setup_fonts.py
python -m unittest discover -s tests -v
python render.py --brief projects/cadence.json --validate-only
python render.py --brief projects/cadence.json --out output --stills
# Inspect output/review/storyboard.jpg before rendering.
python render.py --brief projects/cadence.json --out output
python verify_export.py output/cadence-bravado.mp4

The starter export is 1920 × 1080, 30 fps, 31 seconds, H.264 video with AAC stereo audio. The editable Bravado pitch source and pitch brief show how the renderer can be adapted to tell a different product story. Successful render workflows retain downloadable artifacts subject to GitHub access and retention; the commands above provide a local reproduction path.

Prototype boundaries

This is an agent-guided workflow and starter renderer, not a one-click hosted video service. Source inspection collects public metadata; an agent or editor must verify claims and adapt the visual metaphor. The fixed seven-scene starter needs code changes for unrelated product narratives. Automated export checks do not replace storyboard review or watching and listening to the complete film.
